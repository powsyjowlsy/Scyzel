## Verified Project Architecture & Data Contracts
1. **Zero Fabricated Weather Data**: Real meteorological telemetry is fetched live from Open-Meteo for Carcar City coordinates (`latitude=10.11`, `longitude=123.64`) with robust offline cached fallbacks.
2. **PAGASA Heat Index Classification**: Employs the Rothfusz regression equation for heat index calculation, categorizing output into official DOST-PAGASA tiers:
   - Below 27°C: Not Hazardous
   - 27°C to 32°C: Caution
   - 33°C to 41°C: Extreme Caution
   - 42°C to 51°C: Danger
   - 52°C and above: Extreme Danger
3. **Seven UI/UX Ergonomic Pillars**:
   - Destructive Action Safeguard: 2-step form reset with a 4-second confirmation timeout.
   - Input Masking: Keystroke digit-only sanitization on mobile numbers and student LRNs.
   - Visual Error Highlighting & Auto-Focus: Red `.input-error` borders with automatic `.focus()` on the first invalid field.
   - Auto-Calculations: Dynamic heat index calculation and birthdate-to-age applicant classification.
   - Mobile-First Layout: Breakpoints for 375px, 768px, 1024px, and 1440px with action-bar wrapping and 44px minimum touch targets.
   - Decoupled Native Workflows: Instant browser-native `window.print()` for the admissions prospectus.
   - Dual-Route Distribution: Online inquiry form alongside a printable admissions checklist.
4. **Zero-Emoji Rule**: All graphical icons are implemented using pure SVG paths (Heroicons/Lucide conventions).
